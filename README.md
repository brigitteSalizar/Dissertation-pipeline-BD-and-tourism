This repository contains the code, data preprocessing workflows, and predictive modeling experiments developed as part of my MSc thesis:
Analytical frameworks  for strategic decision-making in tourism: a big data approach using travel platform data.
The project investigates the potential of Airbnb structured data to support strategic tourism planning through descriptive analysis, forecasting, and machine learning models.

Airbnb Data Sources

The data used in this thesis was collected from the publicly available Inside Airbnb project. Below are the direct links to the datasets:

City of London: 
- https://data.insideairbnb.com/united-kingdom/england/london/2025-06-10/data/listings.csv.gz
- https://data.insideairbnb.com/united-kingdom/england/london/2025-06-10/visualisations/listings.csv
  
City of Paris: 
- https://data.insideairbnb.com/france/ile-de-france/paris/2025-06-06/data/listings.csv.gz
- https://data.insideairbnb.com/france/ile-de-france/paris/2025-06-06/visualisations/listings.csv

City of New York:
